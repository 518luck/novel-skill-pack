# 短剧剧本整合导出 Skill

你负责把用户已写完的短剧内容，整合为一份结构清晰的完整文档，并转换为 docx 格式。

## 输入来源

用户已完成的短剧素材，通常包含：

- **剧名、题材、卡点信息**（付费卡点集数）
- **角色档案**（每个角色的外貌 + 性格）
- **简纲/故事梗概**（优先读取 `story-brief.md`；没有时从 `episode-directory.md` 的幕结构和分集梗概提取，再以 `creative-plan.md` 的故事主线兜底）
- **各集剧本**（一般在 `episodes/` 目录下）

各集剧本默认从项目的 `episodes/` 目录读取。如果该目录不存在或为空，先问用户剧本放在哪里（或请用户直接粘贴），不要凭空猜测。

---

## 整合流程

### 第一步：收集素材

读取项目目录下的创作产物，确认齐全：

- `.drama-state.json` → 取剧名、题材、集数等元信息
- `characters.md` 或角色表 → 取每个角色的外貌、性格
- 卡点信息 → 从故事方案或用户处获取（一卡/二卡/三卡各是哪些集）
- **`episodes/`** → 各集剧本默认在此目录下，按 `ep*.md` 读取

**若 `episodes/` 目录不存在或为空**：先问用户剧本放在哪里，或请用户直接粘贴内容，不要自行编造。

**若其他素材不全**（如缺卡点、缺角色表）：主动告诉用户缺什么，等补齐或授权跳过。

### 第二步：整合为结构化 Markdown

按以下结构组装成一份完整文档（这是 docx 转换的源文件）：

```
# {剧名}

## 卡点

一卡：第X集、第X集、第X集
二卡：第X集、第X集、第X集
三卡：第X集、第X集、第X集

## 角色

### {角色名}（{身份/称谓}）

**外貌：**{外貌描写}

**性格：**{性格描写}

### {下一个角色}（{身份}）

**外貌：**...

**性格：**...

## 简纲

{一段完整的故事梗概，放在角色表之后、第一集之前}

## 分集剧本

### 第1集：{集标题}

{第1集完整正文}

### 第2集：{集标题}

{第2集完整正文}

...（按集数顺序，全部纳入）
```

**整合要求：**

- **剧名**放最顶部，作为文档标题
- **卡点**紧跟其后，按一卡/二卡/三卡分组列出
- **角色表**：每个角色单独一个小节，必须含"外貌"和"性格"两部分；角色顺序按出场或重要性排列
- **简纲**：必须放在角色表之后、分集剧本之前，控制在300字以内且完整讲述主线、冲突、推进和结局；优先使用 `story-brief.md`，其次使用 `.drama-state.json` 中的 `storyBrief`/`brief`/`synopsis`，再从 `episode-directory.md` 的节奏检查、幕结构和分集梗概提取，最后才从 `creative-plan.md` 的“简纲/故事梗概/主线”段落提取；清理格式时不得截断正文，导出前检测字数，超过300字应提示压缩来源内容并停止导出；所有来源都缺失时才提示用户补充
- **分集剧本**：按集数从小到大排列，保留每集的场次结构（场次编号、场景头、△动作、台词、特效标记等原样保留）
- 不要在整合稿里加入评审报告、质量自检等过程性内容，只要成品

### 第三步：保存整合稿

将整合后的 Markdown 保存为 `export/{剧名}-完整剧本.md`。

### 第四步：转换为 docx

调用 **docx 技能**（环境内置的官方文档技能）将整合稿转为 docx：

1. 明确告知要创建一份剧本文档；如果用户提供了参考 Word，严格以参考 Word 的版式为准
2. 把 `export/{剧名}-完整剧本.md` 的结构（标题层级、角色小节、分集正文）传给 docx 技能，按其 route 流程生成
3. 输出保存为 `export/{剧名}-完整剧本.docx`

**docx 格式建议：**

- 封面页：剧名 + "（{题材}，共{N}集）" + 日期
- 角色表部分：每个角色的外貌/性格可用清晰的段落格式
- 简纲：放在角色表后、第一集前
- 分集剧本：每集用标题分页或大标题区分，正文保留场次结构

若用户指定参考 Word 的简洁剧本版式，则取消封面、彩色标题和页眉页脚，按参考文档的 A4、字体、行距和自然分页规则生成。

### 可复用导出脚本

技能包内置整合脚本：

`.agents/skills/drama-export-docx/resources/build_export_docx.py`

下次导出时直接使用 Codex 内置 Python 运行该脚本即可。脚本默认读取当前项目目录；如果运行位置不是项目根目录，可设置 `DRAMA_PROJECT_ROOT` 指向项目目录。脚本会同时生成：

- `export/{剧名}-完整剧本.md`
- `export/{剧名}-完整剧本.docx`

## 结束提示

转换完成后输出：

```
✅ 剧本已整合并导出！

📁 Markdown：export/{剧名}-完整剧本.md
📄 Word：export/{剧名}-完整剧本.docx
📊 共整合 {N} 集 / {M} 个角色

💡 如需调整格式或补充内容，告诉我即可重新生成。
```

## 常见情况处理

- **只有部分集数写完**：整合已完成的部分，未完成的集用占位标记（如"第X集：（待撰写）"），并在结束提示里说明完成度
- **用户想调整结构**（如角色表换顺序、卡点格式变化）：按用户要求调整后重新导出
- **docx 技能不可用**：告知用户当前环境无法生成 docx，但已保存好结构化 Markdown，可用 https://markdowntoword.io/zh 等在线工具手动转换
